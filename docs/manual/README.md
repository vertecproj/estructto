# Manual do Estructto

Manual do usuário do Estructto unificado, para engenheiros estruturais. Organizado por tarefa, na ordem do fluxo de trabalho
(a mesma ordem das abas da faixa).

> **AVISO.** O Estructto é ferramenta de apoio. Todo resultado exige verificação por engenheiro responsável, com ART.
> Leia [Limitações e responsabilidade](11-limitacoes.md) antes de usar um resultado em projeto.

## Capturas

As capturas de tela ficam em `C:\dev\build\...\capturas`, fora do repositório. O manual as cita pelo nome do arquivo,
por exemplo "(captura 29-acoes-vento)". Gere-as com `Estructto.exe --capturas`.
